# レコード屋 路地灯

架空のレコードショップを経営するシミュレーター（PCブラウザ向け・単一HTML）。

## 遊び方（v0.1）
1. 開店前は時間が止まっています。棚を見て回り、準備ができたら「開店する」
2. 営業は 10:00〜19:00（実時間で約30分）。お客さんの言葉を読んで、合いそうなレコードを棚から探して渡す
3. 注文に全部合えば大満足（心付けあり）、一部だけならまあまあ、外すと評判が下がる。予算オーバーも断られる
4. 19:00で閉店して精算。翌日へ

タブを離れると自動で一時停止します。進行はブラウザに保存されます。

`index.html?debug` で開くと時間の早送り（×10・×60）とデータ消去ボタンが出ます。
